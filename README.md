## About

Brim is a desktop launcher built around one idea: managing Minecraft should stay simple even when a setup is not.

It keeps game instances, versions, mod loaders, mods and launcher settings in one place, while giving each instance its own configuration.

The project is currently under active development. This repository is the public home for project information, screenshots and future releases.

## What Brim is being built for

- Separate Minecraft instances with their own files and settings
- Vanilla Minecraft and popular mod loaders
- Browsing and installing mods and modpacks
- Modrinth and CurseForge integrations
- Importing existing instances from other launchers
- Microsoft account sign-in for Minecraft: Java Edition
- Per-instance Java, memory and launch settings
- Configurable appearance and accent colors
- A native Windows desktop experience

Some of these features are still being developed and may change before the first public release.

## Accounts

Brim uses its own Microsoft Entra application and the official Microsoft, Xbox and Minecraft authentication services.

Users sign in through Microsoft's authentication flow. Brim does not ask for or store Microsoft account passwords.

Access to Minecraft Services for Brim's Application ID is currently pending review.
